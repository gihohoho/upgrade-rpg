# 일반 장비 AI 아이콘 적용 규칙 — v368

## 현재 적용 범위

- 대상: 일반 보스 1~39단계의 일반 장비 195개
- 결과: 장비마다 별도 256×256 PNG 1개, 총 195개
- 위치: `src/assets/equipment/`
- 파일명: `tier-{두 자리 단계}-{장비 종류}.png`
- 캐시 식별자: `?v=368`
- 생성 도구: Codex built-in `image_gen`
- 외부 API key, extension, 프로젝트 dependency 설치: 없음

장비 종류와 파일명은 다음 다섯 가지로 고정합니다.

```txt
skill_all    -> skill-all
atk_inc      -> atk-inc
normal_dmg   -> normal-dmg
skill_chance -> skill-chance
normal_crit  -> normal-crit
```

예를 들어 13단계 다섯 장비는 `tier-13-skill-all.png`,
`tier-13-atk-inc.png`, `tier-13-normal-dmg.png`,
`tier-13-skill-chance.png`, `tier-13-normal-crit.png`를 사용합니다.

## 게임 연결

`src/utils/icon-utils.js`는 이름에서 이미지를 추측하지 않습니다. 일반 장비의
`tier`와 `equipGroup` 조합으로 정확한 로컬 파일 하나를 선택합니다.
보스 드롭 원본, 런타임 아이템, 저장 데이터의 가방·보관함·휴지통·장착칸,
관리창과 지급 미리보기는 모두 `normalizeItemIcon()` 경로를 사용합니다.

## 이미지 공통 규격

- 정확한 1:1 정사각형, 최종 256×256 PNG
- 이미지 안쪽에 카드, 희귀도 테두리, 액자, inset panel, margin band 없음
- 빈 여백 없이 아이템과 효과가 화면을 크게 채우는 close-up
- 일부가 잘려도 64px 슬롯에서 장비 종류를 바로 알아볼 수 있는 구도
- 고전 한국식 횡스크롤 판타지 액션 RPG의 선명한 만화형 장비 아이콘
- 굵고 선명한 외곽선, 읽기 쉬운 실루엣, 목적 있는 금속·보석 하이라이트
- 글자, 숫자, 로고, 워터마크, 무관한 날개, 물체를 가리는 과도한 입자 금지

PNG 내부에는 등급 프레임을 그리지 않습니다. 게임 UI의 CSS가 기본 흰색부터
상위 색상·이중선·광채까지 등급 테두리를 별도로 적용하며, 장착칸·가방·보관함·
휴지통·관리창·지급 미리보기에서 동일하게 유지합니다.

## 같은 계열의 발전 규칙

같은 계열도 파일을 공유하지 않고 단계마다 별도 PNG를 사용합니다. 상위 단계는
바로 전 단계 이미지를 편집 원본으로 사용해 다음 요소를 유지합니다.

- 물체 정체성과 종류
- 실루엣과 카메라 각도
- 화면 안 배치와 크롭
- 주요 부품과 중심 장식 위치

단계가 오를수록 재질, 중심색, 기존 부품의 장식, 룬과 마력 효과만 점진적으로
발전시킵니다. 전혀 다른 물체로 재설계하거나 CSS 테두리만 바꿔 승급 이미지를
대신하지 않습니다.

대표 계열은 다음과 같습니다.

- 13→14→15: 기본 이름 → `-진-` → `★심연★`
- 21→22→23: 기본 → 상위 → 초월
- 24→25→26: 기본 → 상위 → 초월
- 10→11→12→18→19→20: 기본 → 진 → 초월 → 연옥 → 진 연옥 → 초월 연옥
- 30→31→35→36: 기본 → 상위 → 초월 → 해방

계열 판정은 고정 접두어에만 의존하지 않습니다. 승급 표식을 제거한 이름이 같거나,
더 긴 상위 이름에 기본 장비 이름 전체가 포함되면 같은 계열입니다. 이미 확정된
단계표가 있으면 이름 키워드보다 단계표를 우선합니다.
