# 일반 장비 AI 아이콘 적용 규칙 — v365

## 완료 범위

- 대상: 일반 보스 1~39단계의 일반 장비 195개
- 결과: 장비마다 별도 256×256 PNG 1개, 총 195개
- 위치: `src/assets/equipment/`
- 파일명: `tier-{2자리 단계}-{장비 종류}.png`
- 캐시 식별자: `?v=365`
- 이전 이름 기반 임시 PNG 20개: 연결 해제 후 삭제

장비 종류별 파일명은 다음 다섯 가지로 고정합니다.

```txt
skill_all    -> skill-all
atk_inc      -> atk-inc
normal_dmg   -> normal-dmg
skill_chance -> skill-chance
normal_crit  -> normal-crit
```

예를 들어 13단계의 다섯 장비는
`tier-13-skill-all.png`, `tier-13-atk-inc.png`,
`tier-13-normal-dmg.png`, `tier-13-skill-chance.png`,
`tier-13-normal-crit.png`를 사용합니다.

## 실제 게임 연결

`src/utils/icon-utils.js`는 일반 장비의 표시 이름을 추측하지 않습니다.
`tier`와 `equipGroup`을 조합해 정확한 파일 하나를 선택합니다.
따라서 이름에 `-진-`, `★심연★`, `★연옥★`, `[기본]`,
`끝없는`, `영원한` 같은 표식이 추가되어도 이미지가 다른 장비와
잘못 공유되지 않습니다.

보스 드롭 원본, 새 획득 아이템, 저장 데이터의 가방·보관함·휴지통·
장착칸·우편은 기존 `normalizeItemIcon()` 경로를 통해 같은 규칙을
사용합니다.

## 같은 계열의 발전 규칙

같은 이름을 바탕으로 승급한 장비는 파일을 공유하지 않고 단계마다
별도 PNG를 사용합니다. 다만 사용자가 같은 계열임을 알아볼 수 있도록
기본 물체의 실루엣, 카메라 각도, 구도와 주요 부품은 유지합니다.
상위 단계에서는 재질, 색상, 장식, 룬과 마력 효과를 점진적으로
발전시킵니다.

대표적인 같은 계열은 다음과 같습니다.

- 13·14·15단계: 기본 이름 → `-진-` → `★심연★`
- 21·22·23단계: 기본 이름 → `-진-` → `끝없는 ...`
- 24·25·26단계: 기본 이름 → `-진-` → `영원한 ...`
- 10·11·12·18·19·20단계: 기본 → 진 → 초월 → 연옥 → 진 연옥 → 초월 연옥
- 이름에 `[기본]`이 들어간 장비와 그 상위 장비도 같은 계열

이 규칙은 PNG를 공유한다는 뜻이 아닙니다. 195개 장비는 항상 195개의
서로 다른 파일 경로를 가집니다.

## 이미지 규격과 화풍

- 정확한 1:1 정사각형, 최종 256×256 PNG
- 이미지 내부 카드·테두리·액자·글자·숫자·로고·워터마크 없음
- 빈 여백 없이 장비와 효과가 화면을 크게 채우는 close-up
- 일부가 잘려도 64px에서 장비 종류를 한눈에 알아볼 수 있는 구도
- 한국식 횡스크롤 판타지 액션 RPG의 만화형 장비 아이콘
- 굵고 선명한 외곽선, 읽기 쉬운 실루엣, 셀 셰이딩과 금속 하이라이트
- 이전 시안보다 조금 화려하되, 장비 형태를 가리는 과도한 입자·날개·광채는 금지

PNG 내부에는 등급 프레임을 그리지 않습니다. 게임 UI의 CSS가 기본
흰색부터 상위 색상·광채까지 등급 테두리를 별도로 적용합니다. 이
프레임은 장착칸, 가방, 보관함, 휴지통, 관리창과 지급 미리보기에서
동일하게 유지됩니다.

## 생성 도구와 보안

Codex built-in `image_gen`을 사용했습니다. 외부 API 키, 새 extension,
프로젝트 dependency 설치는 없습니다. 생성 원본은 Codex 사용자
저장소에 있고, 게임에는 규격을 맞춘 256×256 PNG만 포함합니다.

## 검증 계약

`tools/smoke/game/smoke_equipment_icon_families.js`는 다음을 확인합니다.

- 1~39단계 일반 장비 195개
- 다섯 `equipGroup`과 39개 단계 전체 포함
- 모든 장비에 서로 다른 정확한 `tier + equipGroup` URL 적용
- 195개 PNG의 signature와 256×256 크기
- 캐시 식별자 `?v=365`

`tools/smoke/frontend/smoke_legacy_static_deployment_preparation.js`는
정적 배포 산출물에도 195개 단계별 PNG가 빠짐없이 포함되는지
확인합니다.

장비 능력치, 강화 공식, 드롭률, backend API/image, Neon DB와 Render
서비스는 이번 이미지 작업에서 변경하지 않았습니다.
