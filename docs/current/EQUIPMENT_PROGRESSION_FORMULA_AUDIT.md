# 장비 성장 공식 감사와 12단계 이후 스킬 피해 기준 — v356

## 결론

- 일반 보스 1~12단계에는 단계마다 일반 장비 5종이 있고 총 60종입니다.
- 같은 범위의 특수장비 탈리스만 5종도 별도로 감사해 총 65종을 확인했습니다.
- `skill_all`, `atk_inc`, `normal_dmg`, `skill_chance`, `normal_crit`가 각 단계에 하나씩 있으며 누락·중복은 없습니다.
- 12-1 `-초월- 어둠을 지배하는 고리 +20`의 공격력은 이미 `69.1B`로 맞습니다.
- 기존 스킬 피해는 내부 `488.6%`였고, 이번에 요청 기준인 `607.0%`로 변경했습니다.
- 모든 피해는 요청대로 수정하지 않았습니다. 내부 계산은 기존 `173.9%`, 현재 화면의 세 자리 유효숫자 표시는 `174%`입니다.
- 모든 장비와 옵션을 관통하는 단 하나의 공식은 없습니다. 1~11단계는 고정 기본값과 옵션별·단계별 분기이고, 12단계 이상은 별도 생성·보간 공식입니다.
- 이번 변경 대상인 스킬 피해 장비에는 일관된 공식이 있으며, 12단계 기준을 13~39단계와 앞으로 추가될 고단계에도 자동 투영합니다.

## 데이터와 런타임 권위

1. 1~11단계 장비 기본값은 `src/data/bosses.js`의 확정 데이터입니다.
2. 12~39단계 장비 기본값은 `src/data/boss-factories.js`에서 생성합니다.
3. 실제 강화 결과는 `src/systems/stat-system.js`의 `calcItemStats()`가 계산합니다.
4. backend seed와 Neon의 장비 값은 +0 기본값입니다. +20 결과는 저장하지 않고 브라우저 런타임에서 계산합니다.

따라서 이번 변경은 +0 `baseSdmg`나 DB를 바꾸지 않고, 12단계 이상 스킬 피해의 강화 증가분만 조정했습니다.

## 새 고단계 스킬 피해 공식

단계를 `t`, 강화 레벨을 `l`이라고 두면:

```txt
기본 스킬 피해 B(t) = 10 × t
강화 증가분 d(l) = enhanceTable[l].sdmg - enhanceTable[0].sdmg
기존 단계 성장 G(t) = 1 + 0.6 × (t - 1)
```

12단계 +20의 기존 강화 증가분은:

```txt
d(20) = 58.5 - 10 = 48.5
G(12) = 7.6
기존 결과 = 120 + 48.5 × 7.6 = 488.6%
```

기본값 120을 유지하면서 목표 607을 맞추는 고단계 강화 보정값은:

```txt
K = (607 - 120) ÷ (48.5 × 7.6)
  = 1.321215409658...
```

최종 공식은 다음과 같습니다.

```txt
1~11단계:
S(t,l) = round1(B(t) + d(l) × G(t))

12단계 이상:
S(t,l) = round1(B(t) + d(l) × G(t) × K)
```

이 방식은 +0 기본값과 기존 강화 곡선 모양을 유지합니다. +20 전용으로 정리하면 12단계 이상에서 약 `단계당 48.4473684%p` 증가합니다.

점검한 예외와 구간 공식:

- 공격력: 1~11단계는 기본값과 `1.52^(단계-1)` 강화 배율, 12단계 이상은 확정 기준점과 보간·외삽을 사용합니다.
- 스킬/모든 피해 기본값: 각각 `10 × 단계`, `5 × 단계`로 1~39단계 seed까지 일치합니다.
- 공격력 추가 기본값: 1~12단계에서 `5 × 단계 + 5`입니다. 강화는 6·7단계 전용 배열과 8단계 이상 분기가 있습니다.
- 평타 피해 기본값: 4~12단계는 `25 × (단계-1)`이고 1~3단계는 기존 확정값 `40/50/60`입니다.
- 추가 스킬 배율과 평타 치명 배율: 단계별 고정값, 6·7단계 전용 배열, 8~11단계 상수 분기, 12단계 이상 보간식이 섞여 있습니다.
- 탈리스만 5종은 일반 스탯 장비가 아니라 스킬 레벨을 올리는 특수 장비입니다. 강화 범위는 +0~+6이고 스킬 레벨 보너스는 `강화 레벨 + 1`입니다. +0/+6 모두 일반 공격·피해 스탯 0을 확인하고 위 60종 표와 분리했습니다.

이 예외들은 누락이 아니라 기존 확정 장비값을 보존하기 위한 명시적 분기입니다.

## 회귀 검증

`tools/smoke/game/smoke_equipment_progression_formulas.js`가 다음을 고정합니다.

- 1~12단계 일반 장비 60종의 +0/+20 결과
- 1~12단계 탈리스만 5종의 +6 상한, `강화 레벨 + 1` 스킬 보너스, 일반 스탯 0 유지
- 모든 0~20 강화 레벨의 단조 증가
- 12단계 `69.1B / 607% / 기존 173.9%`
- 12~39단계 스킬 피해 새 공식과 단조 증가
- 12~39단계 2,940개 장비/강화 조합의 스킬 피해 외 수치 SHA-256 불변
- 아직 데이터에 없는 합성 40단계에도 같은 고단계 공식 적용
- 비대상 장비의 스킬 피해 0 유지
- 1~39단계 source/template/drop seed 기본값 일치

실제 공개 게임 반영에는 backend나 DB 작업이 아니라 기존 Render Static Site 수동 배포 1회만 필요합니다. 다만 다음 단계에서 static-only fail-closed 계약/checker를 먼저 준비하고, 그 gate 준비 commit의 별도 exact-SHA 승인을 받은 뒤에만 실행합니다.
