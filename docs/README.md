## 인수인계

```txt

NEXT_CHAT_HANDOFF.md

```

루트 인수인계 파일과 `docs/handoff/` 사본은 같은 v300 기준으로 유지합니다.

`local-backups/`와 `local-review-artifacts/`는 Git/전달 ZIP에서 제외합니다.
