# 관리자 페이지 요구사항 초안

## 목적

관리자 페이지는 코드를 직접 수정하지 않고 게임 데이터를 바꾸기 위한 화면입니다.

기호가 운영 중 바꿀 가능성이 높은 값들은 코드가 아니라 DB에서 관리해야 합니다.

---

## 1차 관리자 메뉴

```txt
아이템 관리
보스 관리
드랍률 관리
필드존 관리
강화 규칙 관리
스킬 관리
캐릭터 관리
```

---

## 2차 관리자 메뉴

```txt
변경 이력
```

## 캐릭터 추가 원칙

앞으로 캐릭터가 추가될 예정입니다.

중요 원칙:

```txt
캐릭터마다 다른 것은 스킬뿐입니다.
아이템/보스/드랍/강화/필드/재화 시스템은 공통입니다.
```

따라서 DB/백엔드 구조도 아래처럼 잡습니다.

```txt
공통:
아이템, 보스, 드랍, 강화, 필드, 재화, 인벤토리

캐릭터별:
캐릭터 정보, 스킬 정보, 스킬 레벨, 각성 상태
```

## 필수 안전장치

관리자 페이지는 자유도가 높은 만큼 안전장치가 필요합니다.

```txt
수정 이력 저장
수정 전 값 저장
수정 후 값 저장
누가 수정했는지 저장
언제 수정했는지 저장
되돌리기 기능
권한 체크
운영/개발 테스트 기능 분리
```
