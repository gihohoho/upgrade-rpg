# Generated Reports

이 폴더는 checker/report가 다시 만드는 결과물입니다. 직접 편집하지 않습니다.

- `BACKEND_ROUTE_MAP.md`: backend route 목록
- `BACKEND_STRUCTURE_PLAN.md`: backend 모듈 구조 보고서
- `LEGACY_PATH_DEPENDENCIES.md`: legacy 정적 경로 의존성
- `POSTGRES_ALEMBIC_READINESS.md`: source head와 적용 DB 상태

생성 명령과 검사는 각 파일 머리말 또는 `tools/README.md`를 봅니다.
