## 결론

- 일반 보스 1~12단계에는 단계마다 일반 장비 5종이 있고 총 60종입니다.
- 같은 범위의 특수장비 탈리스만 5종도 별도로 감사해 총 65종을 확인했습니다.
- `skill_all`, `atk_inc`, `normal_dmg`, `skill_chance`, `normal_crit`가 각 단계에 하나씩 있으며 누락·중복은 없습니다.

- 16단계 `무의식 : 넥스의 몽환의 어둠 +20`은 공격력 `369B`와 모든 피해 내부 `225.8%`를 유지하고 스킬 피해만 `800.8% → 2121.0%`로 변경했습니다.

- 저장소에는 `607%@12`와 `2121%@16`을 함께 설명하는 원본 스킬 피해 공식이나 17단계 이후 실측 스킬 피해 기준이 없습니다.
- 따라서 기존 공격력·치명 피해와 같은 기준점 기하성장 방식을 적용했습니다. 12~16단계는 보간하고 17단계 이후는 새 실측 기준이 생기기 전까지 같은 비율로 추정 외삽합니다.

## 데이터와 런타임 권위

1. 1~11단계 장비 기본값은 `src/data/bosses.js`의 확정 데이터입니다.
2. 12~39단계 장비 기본값은 `src/data/boss-factories.js`에서 생성합니다.
3. 실제 강화 결과는 `src/systems/stat-system.js`의 `calcItemStats()`가 계산합니다.
4. backend seed와 Neon의 장비 값은 +0 기본값입니다. +20 결과는 저장하지 않고 브라우저 런타임에서 계산합니다.

따라서 이번 변경은 +0 `baseSdmg`나 DB를 바꾸지 않고, 12단계 이상 스킬 피해의 런타임 강화 결과만 조정했습니다.

## 새 고단계 스킬 피해 공식

단계를 `t`, 강화 레벨을 `l`이라고 두면:

```txt
기본 스킬 피해 B(t) = 10 × t
강화 진행률 P(l) =
  (enhanceTable[l].sdmg - enhanceTable[0].sdmg)
  ÷ (enhanceTable[20].sdmg - enhanceTable[0].sdmg)
```

두 확정 +20 기준과 단계당 비율은:

```txt
T20(12) = 607
T20(16) = 2121
R = (2121 ÷ 607)^(1 ÷ 4)
  = 1.36721871444...
```

단계별 +20 목표와 최종 강화 공식:

```txt
1~11단계:
기존 공식을 그대로 유지

12단계 이상:
T20(t) = round1(607 × R^(t - 12))
S(t,l) = round1(B(t) + (T20(t) - B(t)) × P(l))
```

이 방식은 +0 기본값과 기존 강화 곡선 모양을 유지하고, +20에서 두 실측 기준을 정확히 통과합니다. 선형식은 단계가 올라갈수록 상대 성장률이 계속 낮아지고, 공격력의 약 `1.52`배를 빌리면 16단계 이후 갑자기 지나치게 커지므로 사용하지 않았습니다. 새 `1.3672`배는 기존 11→12단계 스킬 피해 약 `1.3504`배와 고단계 치명 기본값 약 `1.35`배에 가깝습니다.
