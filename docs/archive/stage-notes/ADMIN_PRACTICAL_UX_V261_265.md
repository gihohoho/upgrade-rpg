# Admin Practical UX Bundle v261-v265

이 문서는 관리자 페이지를 처음 보는 사람도 부담 없이 읽고 사용할 수 있게 정리한 UX 묶음입니다.

## 범위

- v261: 첫 진입 안내와 초보자 추천 순서 강화
- v262: 마스터 데이터 카탈로그 도메인별 컬럼 프리셋
- v263: 긴 값은 표에서 줄이고 모달에서 전체 보기
- v264: 버튼 위험도 색상/라벨 체계
- v265: 상세 화면의 다음 행동 안내와 읽기 순서 정리

## 안전 기준

이번 묶음은 UI 표시와 읽기 흐름만 바꿉니다.

- DB 변경 없음
- env 변경 없음
- seed 변경 없음
- 인증 변경 없음
- 기존 route 변경 없음
- API 응답 body 변경 없음
- Write Guard 변경 없음
- 실제 write 로직 변경 없음

## 확인 포인트

1. 관리자 첫 화면에서 처음 사용하는 추천 순서가 보이는지 확인합니다.
2. 버튼 옆 색상/라벨이 조회, Preview, 적용주의, 고위험으로 나뉘는지 확인합니다.
3. 마스터 데이터 카탈로그에서 기본 보기/자세히 보기/JSON 보기를 선택할 수 있는지 확인합니다.
4. 기본 보기는 도메인별 핵심 컬럼만 보여주는지 확인합니다.
5. 긴 값은 표 안에서 줄어들고 전체 버튼을 누르면 모달로 전체 내용이 보이는지 확인합니다.
6. 상세 화면 상단에 선택 항목 요약과 다음 행동 버튼이 보이는지 확인합니다.

## v266 feedback adjustment

v262의 `보기 방식` 선택은 사용자 피드백에 따라 롤백되었습니다. 최신 기준에서는 마스터 데이터 카탈로그가 다시 단일 목록으로 동작하고, 긴 값은 짧은 미리보기 + `전체` 모달로 확인합니다. 버튼 위험도는 문구 chip이 아니라 색상과 tooltip으로만 전달합니다.
