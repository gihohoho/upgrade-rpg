# PostgreSQL baseline 완료 기록

이 폴더는 v282~v304에서 완료된 PostgreSQL/Alembic 최초 baseline 작업의 단계별 기록을 보관합니다.

현재 운영 기준은 `docs/current/`의 다음 문서를 먼저 봅니다.

- `POSTGRES_BASELINE_COMPLETION_STATE.md`
- `POSTGRES_NEXT_REVISION_PREFLIGHT.md`
- `POSTGRES_DEPLOYMENT_RUNTIME_READINESS.md`
- `POSTGRES_RUNTIME_CONFIG_HARDENING.md`

여기의 문서는 과거 실행 증거와 안전 경계를 보존하기 위한 archive입니다. 이미 완료된 `stamp`, `upgrade`, `downgrade`, DB 생성·복원 명령을 다시 실행하는 지침으로 사용하지 않습니다.
