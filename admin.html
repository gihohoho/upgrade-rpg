Upgrade RPG 관리자 페이지

마스터 데이터 allow-list 필드를 실제 DB에 적용하고, 변경 이력 되돌리기, 인게임 영향 안내, 적용/되돌리기 후 master-data API 자동 확인까지 함께 점검합니다.

게임으로 돌아가기
이 페이지는 관리자 화면으로 옮기기 전의 안전한 뼈대입니다. 마스터 데이터 allow-list 필드는 타입별 입력 UI + 검증 + 확인 문구 + dev key를 거쳐 실제 DB 적용이 가능하고, 변경 전 영향 안내와 변경 후 /game/master-data API 반영 확인을 제공합니다. localStorage와 현재 게임 런타임은 직접 수정하지 않습니다.
주의: 지급/삭제/JSON/이미지/관계 코드 변경은 아직 막혀 있습니다. 실제 적용/되돌리기는 name, description, 수치 밸런스, is_enabled 등 좁은 필드만 가능합니다.

필드 용어 도움말
관리자 페이지에서 자주 헷갈리는 값입니다. 표 제목이나 편집 초안 입력칸 옆의 ? 에 마우스를 올려도 같은 설명을 볼 수 있습니다.
grade / 등급 숫자

현재 이 프로젝트에서는 일반적인 normal/rare/epic 희귀도명이 아니라, 기존 JS 아이템의 tier 숫자를 옮겨 담은 값입니다.

예: grade=1은 1티어/초반 구간, grade=12는 12티어/상위 구간입니다. 희귀도 이름이 필요하면 나중에 rarity 필드로 분리하는 편이 안전합니다.
enhance group code / 강화그룹 코드

이 아이템이 어떤 강화 규칙 묶음을 사용할지 연결하는 코드입니다. 아이템의 enhance_group_code와 강화 그룹의 code가 같으면 해당 강화 그룹/강화 단계가 적용됩니다.

예: weapon_basic 아이템 → enhancementGroups.code=weapon_basic → enhancementLevels.group_code=weapon_basic
admin note / 관리자 메모

게임 플레이 화면에는 보여주지 않는 운영자용 메모입니다. 데이터 작업 이유, 주의사항, 임시 설명, 나중에 확인할 내용을 적어두는 내부 기록용 필드입니다.

예: 밸런스 조정 예정, 이벤트 드랍 전용, 아직 미사용 데이터 등
stackable / 겹치기 가능 여부

같은 아이템을 인벤토리 한 칸에 수량으로 합칠 수 있는지 정하는 true/false 값입니다.

true: 재료/강화권처럼 한 칸에 여러 개 쌓임 · false: 장비처럼 각각 별도 칸 사용
값 해석 힌트

상세/편집 초안/카탈로그에서 grade 같은 헷갈리는 값은 실제 값 아래에 짧은 해석이 같이 표시됩니다.

예: grade 7 → tier 7 · 원본 아이템 tier 값
관리자 쓰기 dev key 잠금
조회/미리보기는 그대로 가능하지만, 검증 후 실제 적용과 검사 후 되돌리기는 여기서 dev key를 설정해야 백엔드가 허용합니다. 이 키는 임시 로컬 개발용 안전장치이고, 나중에 로그인/RBAC로 대체할 예정입니다.
확인 중...
기본 로컬 예시 키는 local-admin-dev-key 입니다. 실제 배포 전에는 이 임시 키 방식이 아니라 로그인/권한 관리로 바꿔야 합니다.
마스터 데이터 카탈로그
