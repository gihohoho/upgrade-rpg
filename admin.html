필드 용어 도움말
관리자 페이지에서 자주 헷갈리는 값입니다. 카탈로그 목록은 짧게 보이도록 핵심 라벨만 표시하고, 자세한 설명은 표 제목이나 편집 초안 입력칸 옆의 ? 에 마우스를 올려 확인합니다.
자주 보는 기본 필드
code / 코드

게임 데이터끼리 연결할 때 쓰는 고유 문자열입니다. 다른 row가 이 값을 참조할 수 있으므로 이름보다 더 조심해서 바꿉니다.

예: itemTemplates.code, skills.code, bosses.code, fieldZones.code
name / 이름

관리자와 게임 화면에서 사람이 읽는 표시 이름입니다. code와 달리 표시용이라 비교적 수정 부담이 낮지만, 드랍/툴팁 노출 여부는 확인합니다.

예: 초보자 스태프, 고블린 왕, Q 스킬 이름
grade / 등급 숫자

현재 이 프로젝트에서는 normal/rare/epic 희귀도명이 아니라, 기존 JS 아이템의 tier 숫자를 옮겨 담은 진행 등급입니다.

예: grade=1은 초반 구간, grade=12는 상위 구간
is enabled / 활성 상태

관리자에는 남겨두되 실제 게임 기준 데이터로 쓸지 정합니다. 테스트/미사용 데이터는 false가 안전합니다.

true=사용, false=비활성/숨김 후보
sort order / 정렬값

목록이나 게임 화면에서 보여줄 순서를 정하는 숫자입니다. 보통 작을수록 앞에 표시합니다.

10, 20, 30처럼 간격을 두면 중간 추가가 쉽습니다.
admin note / 관리자 메모

게임 화면에는 보여주지 않는 운영자용 메모입니다. 작업 이유, 주의사항, 밸런스 예정 내용을 적어둡니다.

예: 이벤트 드랍 전용, 추후 밸런스 조정 예정
아이템·장비 필드
item type / 아이템 분류

일반 장비, 스킬강화권, 특수 장비처럼 아이템의 큰 성격을 정합니다.

normal=일반 장비, skill_book=스킬강화권, special_equip=특수 장비
equip slot / 장착칸

장비가 들어갈 일반/특수 슬롯입니다. 잘못 바꾸면 장착 위치와 툴팁이 어색해질 수 있습니다.

skill_all=일반장비 1, atk_inc=일반장비 2, 6=특수무기, 14=휘장
stackable / 겹치기 가능 여부

같은 아이템을 인벤토리 한 칸에 수량으로 합칠 수 있는지 정하는 true/false 값입니다.

true=재료/강화권, false=강화·옵션이 따로 필요한 장비
enhance group code / 강화그룹 코드

아이템이 어떤 강화 규칙 묶음을 사용할지 연결합니다. 아이템의 enhance_group_code와 강화 그룹 code가 연결됩니다.

talisman_emblem=탈리스만/휘장 강화 묶음
base stats / 기본 능력치 JSON

공격력, 피해 증가 같은 기본 옵션 묶음입니다. 원본 JSON은 목록에서 숨기고 상세 미리보기에서만 축약 표시합니다.

예: atk, allDamage, skillDamage 계열
json keys / JSON 키

긴 JSON 전체를 보여주지 않고 어떤 JSON 묶음이 있는지만 알려주는 안전 요약입니다.

예: baseStats, options, rules, conditions
스킬·전투·보상 필드
slot key / 스킬 슬롯

스킬이 Q/W/E/R/T/F/D/M 또는 각성 슬롯 중 어디에 배치되는지 나타냅니다.

중복 슬롯이 생기면 UI 배치가 헷갈릴 수 있습니다.
proc rate / 발동 확률

스킬이나 추가 효과가 발동할 기본 확률입니다. 보너스 필드와 합산되어 최종 표시에 영향을 줄 수 있습니다.

예: 기본 발동률 + 장비/스킬레벨 보너스
cooldown seconds / 쿨타임

스킬 또는 보스 재등장 대기 시간입니다. 단위는 초 기준으로 표시합니다.

예: 30이면 30초
damage multiplier / 피해 배율

스킬 레벨별 피해 배율입니다. 너무 크게 올리면 밸런스가 급격히 바뀔 수 있습니다.

예: 1.25는 125% 계열 배율
hp / enemy hp

보스 체력 또는 필드 몬스터 체력입니다. 골드 보상/드랍과 함께 밸런스를 확인합니다.

bosses.hp, fieldZones.enemyHp
gold reward / 골드 보상

필드나 전투에서 획득하는 골드 기준값입니다. 체력과 함께 성장 속도에 직접 영향을 줍니다.

필드존 보상 조정 시 enemyHp와 같이 확인
관계·드랍·강화 필드
owner type / owner code

드랍 테이블이 보스 소유인지 필드 소유인지, 그리고 어느 boss/field code에 연결되는지 정합니다.

owner_type=boss → bosses.code, owner_type=field → fieldZones.code
drop table code / item template code

드랍 아이템이 어느 테이블에 속하고 어떤 아이템을 떨어뜨릴지 연결합니다.

dropTableItems.drop_table_code + item_template_code
rate / min / max quantity

드랍 확률과 최소·최대 수량입니다. 확률과 수량을 같이 올리면 보상이 크게 늘어날 수 있습니다.

rate=확률, minQuantity=최소, maxQuantity=최대
from level / to level

강화가 몇 단계에서 몇 단계로 이동하는지 나타냅니다. 같은 그룹 안에서 시작 단계가 겹치면 안 됩니다.

+0→+1, +1→+2 같은 단계 규칙
success rate / gold cost

강화 성공 확률과 강화 비용입니다. 실패 규칙/재료 규칙과 같이 확인해야 합니다.

확률·비용·재료를 함께 바꾸면 체감 난이도가 크게 변합니다.
character code / skill code

캐릭터가 어떤 스킬을 기본으로 가지는지 연결합니다. character_code + skill_code 조합 중복은 차단됩니다.

캐릭터 스킬 연결 테이블에서 사용
